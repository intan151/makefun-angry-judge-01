A deterministic Python entry for the make.fun competition "Angry Judge: The Short Rant Contest". It writes one short, angry, funny rant — 320 characters, a single line — in the voice of an annoyed judge, about the office printer.

> Your Honor, Exhibit A: the office printer. One job. ONE. It waits until the meeting starts in ninety seconds, then declares it is out of cyan. The document is black text. It jams on page one, flashes a light I have never seen in my life, and beeps like IT is the victim. I move to hold this machine in contempt of court.

## Run it

```sh
python3 main.py
```

## How it works

`main.py` (Python 3 standard library only, no network, no randomness) validates the rant (1–400 characters, non-blank, single line, valid UTF-8) and writes it to `/output/entry.txt`. Run it with `python3 main.py`.

Two runs produce byte-identical output (sha256 `52f4e3444a47d6425d44bc5fb99146196d8ba24f0f29f50e59fbec4175132ee9`).
